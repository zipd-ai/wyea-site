Two problems this solves

Both of them show up years later

The document changed

Somebody edits the file after an answer was given. Without a version on record, the answer now points at text that is no longer there.

A new read makes a new record

Nothing is edited in place, so the old record and the old answer both survive.

Old answers still open

March's answer still opens March's document, and can still be checked against it.

Nothing is silently corrected

The system does not quietly re-point an old claim at new text that happens to match.

The version expired

Providers age out version history on a schedule set by the plan the company pays for. Policies and treaties outlive that schedule.

The cache is narrow on purpose

It holds a copy of the pages you have already been given answers from, and nothing else. It does not back up your document store.

Stored once, never changed

The same page is never stored twice, and what is stored cannot be quietly altered afterwards.

It is never authoritative

Your store remains the system of record. The cache exists to show what was read.
