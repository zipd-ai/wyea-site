Every answer keeps its version

Each answer records the document version it came from. You can check it months later.

What gets kept

Which documentNamed, and openable
Which versionThe one that was read
Which passageThe page it sits on
When it was readThe date and time
Who could see itRecorded without the content
What was concludedThe answer as given
Whether it was checkedOr handed to a person
Who askedSo a question has somewhere to go

Two problems it solves

The document changed

Without a version on record, an answer points at text that is gone.

A new read is a new record

Nothing is edited in place.

Old answers still open

March's answer opens March's document.

Nothing is re-pointed

An old claim is never moved to new text that happens to match.

The version expired

Providers drop old versions. Policies and treaties last longer.

A narrow copy

It holds only the pages you were given answers from. It is not a backup.

Stored once, never changed

A stored page cannot be quietly altered.

Never the record

Your own system stays the record.
